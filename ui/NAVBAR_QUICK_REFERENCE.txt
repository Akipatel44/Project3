IMPLEMENTATION:
===============

How It Works:
1. Navbar component renders in MainLayout
2. Gets user.role from AuthContext
3. Uses getMenuByRole() to filter items
4. Displays appropriate menu items
5. Unauthorized items are hidden

Code Flow:
Navbar.jsx
  ↓
  uses useAuth() → gets user.role
  ↓
  uses getMenuByRole(user?.role)
  ↓
  renders menu items from MENU_CONFIG


MENU CONFIGURATION:
===================

Located in: src/config/menuConfig.js

Structure:
{
  SUPER_ADMIN: [
    { id: 'home', label: 'Home', path: '/', icon: 'Home' },
    { id: 'dashboard', label: 'Dashboard', path: '/dashboard', icon: 'BarChart3' },
    // ... more items
  ],
  SUB_ADMIN: [ ... ],
  USER: [ ... ],
  PUBLIC: [ ... ],
}

To Add Menu Item:
- Edit menuConfig.js
- Add item to desired role array
- Icon must match one from iconMap
- Path must match a route in App.jsx

TROUBLESHOOTING:
================

Menu items not showing:
→ Check AuthContext has user.role
→ Verify role matches MENU_CONFIG key
→ Check browser console for errors

Navbar hidden:
→ Check page uses MainLayout
→ Verify z-index: 50 not overridden
→ Check sticky positioning

Mobile menu not working:
→ Check Framer Motion installed
→ Verify screen size < 1024px
→ Clear browser cache
