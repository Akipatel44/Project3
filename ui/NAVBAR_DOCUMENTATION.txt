Navbar Component - Role-Based Menu System
==========================================

OVERVIEW:
=========
A fully responsive navbar component with role-based menu items. Different menu items are shown based on user role:
- SUPER_ADMIN: Full access to all sections (Dashboard, Users, Settings, etc.)
- SUB_ADMIN: Access to content management (Places, Events, Gallery, Settings)
- USER: Access to public content (Places, Events, Gallery)
- PUBLIC: No user logged in (Places, Events, Gallery only)

ROLE DETECTION:
===============

The component gets user role from AuthContext:
```javascript
const { user, logout } = useAuth()
// user.role = 'SUPER_ADMIN' | 'SUB_ADMIN' | 'USER' | null
```

Menu items are retrieved using:
```javascript
const menuItems = getMenuByRole(user?.role)
```

If no user is logged in, PUBLIC menu is shown.


USAGE:
======

The Navbar is automatically included in MainLayout:
```javascript
// In any page using MainLayout:
<MainLayout>
  <div>Your content here</div>
</MainLayout>

// Navbar is automatically rendered
// with correct menu items based on user role
```

Custom integration:
```javascript
import { Navbar } from '@/components/layout'

export default function CustomPage() {
  return (
    <>
      <Navbar />
      <main>Your content</main>
    </>
  )
}
```

EXTENDING THE MENU:
===================

To add new menu items, edit menuConfig.js:

```javascript
export const MENU_CONFIG = {
  SUPER_ADMIN: [
    { id: 'home', label: 'Home', path: '/', icon: 'Home' },
    { id: 'new-item', label: 'New Feature', path: '/new', icon: 'Star' }, // Add here
    // ...
  ],
  // ...
}
```

Available icons (from lucide-react):
- Home, MapPin, Calendar, Image
- BarChart3, Users, Settings
- Add more as needed

INTEGRATION WITH PAGES:
=======================

All pages automatically get Navbar:
- Home
- Places
- Events
- Gallery

- User Management (if SUPER_ADMIN)
- Settings (if admin)

Auth pages (Login, Register, OTP) don't show Navbar
because they use AuthLayout instead of MainLayout.

TROUBLESHOOTING:
================

Menu items not showing:
- Check user.role in AuthContext
- Verify MENU_CONFIG has role entry
- Check browser console for errors

Navbar not visible:
- Verify page uses MainLayout
- Check z-index conflicts
- Verify sticky positioning

Mobile menu not working:
- Check screen size (lg: 1024px)
- Verify Framer Motion is installed
- Check animation playback
