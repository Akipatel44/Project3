HOW IT WORKS:
=============

1. Component Flow:
   App.jsx
   └─ Routes render pages
      └─ MainLayout wraps pages
         └─ Navbar renders (role-based)
         └─ Main content
         └─ Footer

2. Role Detection:
   Navbar → useAuth() → user.role
   └─ getMenuByRole(user?.role)
   └─ Filter menu items
   └─ Render authorized items only

3. Navigation:
   User clicks menu → navigate(path)
   └─ Route updates
   └─ Page component renders
   └─ Active indicator updates

CUSTOMIZATION:
==============

Add Menu Item:
1. Edit src/config/menuConfig.js
2. Add to role array:
   { id: 'new', label: 'Label', path: '/new', icon: 'IconName' }
3. Import icon in Navbar.jsx
4. Add to iconMap object

Change Menu Items:
1. Reorder items in menuConfig.js
2. Remove items by deleting from array
3. Update routes in App.jsx

Add New Role:
1. Add role to MENU_CONFIG
2. Backend returns that role
3. Navbar auto-filters

Add Icons:
1. Import from lucide-react
2. Add to iconMap
3. Use in menuConfig

SECURITY:
=========

⚠️ IMPORTANT:
- Menu filtering is UI-only for UX
- Always validate on backend
- Backend must check user.role for every API
- Return 403 for unauthorized access
- Never trust frontend role checks

Best Practice:
1. Frontend: Hide unauthorized items (UX)
2. Backend: Validate every request (Security)
3. API: Return 403 if unauthorized
4. Frontend: Handle errors gracefully
