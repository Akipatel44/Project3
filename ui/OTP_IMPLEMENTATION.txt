KEYBOARD SHORTCUTS:
====================

In OTP Input Boxes:
- 0-9:         Enter digit and auto-focus next
- Backspace:   Delete current and go to previous
- Left Arrow:  Move to previous box
- Right Arrow: Move to next box
- Ctrl+V:      Paste OTP
- Click:       Select all in box
