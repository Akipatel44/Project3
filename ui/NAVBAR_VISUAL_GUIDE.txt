CLICK INTERACTIONS:
===================

Click Menu Item:
Menu Item → Navigate to path → Page loads → Active highlight updates

Click Hamburger (Mobile):
☰ → Menu slides open → Menu closed state

Click X (Mobile):
✕ → Menu slides closed → Hamburger shown again

Click User Avatar:
👤 → Dropdown menu appears → Click item → Action or close

Click Logout:
Logout → User removed from AuthContext → Redirect to login → Menu resets

Click Login:
Login → Page loads → User can enter credentials → Redirects on success


ANIMATION DETAILS:
==================

Navbar Entrance:
- Slides down from top
- Fade in
- Duration: 300ms
- Easing: easeOut

Menu Items (Mobile):
- Staggered appearance
- Each item: fade + slide left
- Delay: 50ms between items
- Duration: 200ms each

Hover Effects:
- Button: scales to 1.02-1.05
- Smooth transition: 200ms
- Color changes

Tap Effects (Mobile):
- Button: scales to 0.95
- Instant feedback
- Scales back on release

Dropdown Menu:
- Fades in
- Slides down
- Duration: 150ms
- Smooth exit on close

RESPONSIVE BREAKPOINTS:
=======================

Extra Small (<640px): sm
- Full width
- Single column
- Touch optimized

Small-Medium (640-768px): md
- Responsive padding
- Adjusted font sizes
- Touch targets maintained

Medium-Large (768-1024px): lg [NAVBAR BREAKPOINT]
- Hidden: lg:hidden (hamburger menu)
- Visible: hidden sm:inline (nav items)

Large (1024px+): xl
- Full menu bar
- Desktop optimized
- Hover effects

KEYBOARD SHORTCUTS:
===================

- Navigate through menu items
- Navigate through buttons
- Tab order: left to right

- Activate button
- Open dropdown
- Navigate to page

Escape:
- Close dropdown menu

STATES & BEHAVIORS:
===================

1. Loading State:
   - Button shows spinner
   - Disabled during submission
   - No click allowed

2. Disabled State:
   - Opacity: 50% (opacity-50)
   - Cursor: not-allowed
   - No hover effect

3. Active/Current Page:
   - Background: bg-green-100
   - Text: text-green-700
   - Font: font-semibold

4. Hover State:
   - Background: bg-gray-100
   - Scale: 1.05
   - Transition: 200ms

5. Tap/Click State:
   - Scale: 0.95
   - Instant feedback
   - Smooth return

TROUBLESHOOTING:
================

Menu not showing:
✓ Check user.role in AuthContext
✓ Verify MENU_CONFIG has role
✓ Check browser console for errors

Navbar not visible:
✓ Verify page uses MainLayout
✓ Check z-index: 50
✓ Check sticky positioning

Mobile menu broken:
✓ Check screen size < 1024px
✓ Verify Framer Motion installed
✓ Clear browser cache

Icons not showing:
✓ Verify lucide-react imported
✓ Check icon name in iconMap
✓ Check spelling of icon name
